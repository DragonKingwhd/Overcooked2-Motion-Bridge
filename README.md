# Overcooked2 Motion Bridge (双人体感胡闹厨房控制器)

基于计算机视觉（MediaPipe Pose 骨骼关键点追踪）与 Windows Win32 底层硬件扫描码模拟，将普通的 RGB 摄像头或机器人广角深度相机（如 Looper Robotics Insight 9 等）转化为无需任何实体手柄的**双人全身沉浸式体感控制器**，专为 Steam《胡闹厨房 2》（Overcooked! 2）量身定制。

---

## 🌟 核心特性

- **双人无手柄全身追踪**：支持 1~2 名玩家同时站在镜头前，左右站位自动识别绑定 P1（蓝队）与 P2（橙队）。
- **自然人体工学走位**：
  - **左倾 / 右倾**：身体微侧倾驱动角色向左/向右灵敏微移。
  - **前倾 / 后仰 / 微屈膝**：微前倾即向上走，微后仰或自然轻度屈膝即向下走。
  - **起立防回弹保护**：从屈膝恢复站立时启动 0.55s 防回弹硬锁，彻底杜绝起立被误识别为向上。
- **高频自动切菜连点引擎**：
  - 案板前自然做向下挥刀手势，自动激活持续高频剁菜模式（约 9 次/秒），挥刀 1~2 下即可切完食材，告别手臂疲劳。
  - 角色一旦走位、下蹲或高举手拿放物品，自动瞬间切断切菜连击。
- **单手精准交互（拿取 / 放下 / 投掷）**：
  - 举起单手即可拿起食材或放下餐具，放下手臂自带 0.40s 防误触惯性保护。
  - 手持食材时向下挥砍即触发向前投掷。
- **双手叉腰姿态校准**：
  - 游戏开始后从容走位就坐，双手叉腰保持 1 秒即可自动校准零位，彻底告别开机赶时间。
- **画中画与 HUD 监控**：
  - 实时渲染赛博朋克霓虹骨骼图与状态仪表盘，随时按 `F9` 即可在单屏置顶小窗与双屏大窗之间切换。

## 🎮 体感手势对应表

| 游戏动作 | 玩家 1 (P1) 键位 | 玩家 2 (P2) 键位 | 对应体感姿态 |
| :--- | :--- | :--- | :--- |
| **向左移动** | `A` | `Left` | 身体躯干向左侧倾斜 |
| **向右移动** | `D` | `Right` | 身体躯干向右侧倾斜 |
| **向上移动** | `W` | `Up` | 身体微前倾 或 站直拔高 |
| **向下移动** | `S` | `Down` | 身体微后仰 或 自然微屈膝 |
| **拿取 / 放下** | `J` | `Num 1` | 单手自然高举过胸（左右手皆可） |
| **切碎 / 投掷** | `K` | `Num 2` | 胸前向下自然挥刀砍击 |
| **冲刺加速** | `L` | `Num 3` | 身体深前倾瞬间突进 |
| **剧情确认 / 翻页**| `Space` | `Space` | 双手在胸前击掌相碰 |
| **就位校准** | - | - | 双手叉腰保持 1 秒锁定站姿 |

## 🚀 快速启动指南

### 1. 安装依赖

需要 Python 3.10 及以上环境：

```bash
pip install -r requirements.txt
```

### 2. 下载模型权重（若未自带）

```bash
python download_models.py
```

### 3. 运行体感控制器

```bash
python motion_overcooked.py
```

或者直接双击根目录下的启动批处理文件启动游戏与体感程序。

## 🛠️ 故障排查与技术细节

1. **游戏启动防闪退说明**：
   - Windows 11 环境下，请确保关闭第三方的网络驱动注入或虚拟局域网监控组件，避免与 Steam 通信虚函数表冲突导致游戏意外挂起。
   - `direct_input.py` 已针对 64 位 Win32 API 严格重构结构体对齐（`ULONG_PTR = c_size_t`），彻底免疫 `WH_KEYBOARD_LL` 崩溃问题。
2. **快捷功能键**：
   - 按 `C` 键：随时秒级重置对齐当前站姿。
   - 按 `F9` 键：切换单屏画中画置顶小窗与全屏大窗。
   - 按 `Ctrl + Q` 或 `F10` 键：安全释放所有按键并退出程序。
